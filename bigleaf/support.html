Support - BigLeaf

BigLeaf opens large JSON, JSONL, and NDJSON files locally on your Mac. This page covers common support questions.

Contact

Email: k.oikawa119009@gmail.com

What files does BigLeaf open?

  • JSONL and NDJSON logs, including .jsonl, .ndjson, .log, and .txt files whose contents are JSON lines.
  • Large root-array JSON exports, such as database or API dumps whose top level is an array.
  • Single JSON documents in a tree-only view.

How do I open a file?

Use File > Open, press Command-O, or drag a file into the BigLeaf window. BigLeaf detects the format from the file contents, not only from the extension.

Free and Pro

Files up to 100MB are fully usable for free. Larger files open in Preview Mode, where the first 10,000 records are browsable, searchable, and jumpable. The one-time Pro purchase unlocks larger files. Restore Purchases is available from the app menu.

Privacy

Your files never leave your Mac. BigLeaf has no analytics, no accounts, no telemetry, and no cloud sync. See the Privacy Policy.

Troubleshooting

  • If a file is compressed, decompress it first unless the current app version shows it as supported.
  • If a JSONL file contains invalid lines, BigLeaf keeps those lines as raw records instead of stopping the viewer.
  • If purchase restoration does not complete, confirm that you are signed in to the same Apple ID used for the purchase, then use Restore Purchases again.

開けるファイル

  • .jsonl、.ndjson、.log、.txtなど、中身がJSON Lines/NDJSONのファイル。
  • トップレベルが配列の大きなJSONエクスポート。
  • 単一JSONドキュメント。

ファイルの開き方

File > Open、Command-O、またはBigLeafウィンドウへのドラッグ&ドロップで開けます。形式は拡張子だけでなく中身から判定します。

無料版とPro

100MBまでのファイルは無料で全機能を使えます。それより大きいファイルはプレビューモードで先頭10,000レコードを閲覧、検索、ジャンプできます。買い切りのPro購入で大きなファイルが解放されます。購入の復元はアプリメニューから実行できます。

プライバシー

ファイルがあなたのMacから出ることはありません。BigLeafには解析、アカウント、テレメトリ、クラウド同期はありません。詳しくは プライバシーポリシー を確認してください。

困ったとき

  • 圧縮ファイルは、現在のアプリバージョンで対応表示が出ない場合、先に展開してください。
  • JSONL内に不正な行があっても、BigLeafはその行をrawレコードとして残します。
  • 購入の復元が完了しない場合、購入時と同じApple IDでサインインしていることを確認し、もう一度Restore Purchasesを実行してください。
