Privacy

Last updated: 2026-06-14

Sharebar is built so that there is nothing to collect. The app runs entirely on your Mac, offline. This page — the Share Page — runs entirely in your browser.

What this website collects

Nothing. This site has no analytics, no cookies, no local storage of your link contents, no trackers, and makes no external network requests. When you open a Sharebar link, the shared state lives only in the part of the URL after the # (the fragment), which browsers never send to any server. Decoding and reproducing the tool happens locally, in a Web Worker, on your device.

What the app collects

Nothing is sent off your device. The Sharebar app stores only your own preferences (settings, pinned tools, window position) inside its app container. It does not store your clipboard contents, your inputs, your results, or a history of links you generate. It has no analytics or crash-reporting SDK. Its App Store privacy label is Data Not Collected.

Share Links

A Share Link encodes a tool’s state directly in the URL. There is no server and no link shortener — the link is self-contained. Only four tools (regex, cron, color, Unix time) can create a link; data-carrying tools (JSON, diff, Base64, URL encoding, hashing, UUID) deliberately cannot, so confidential data has no path into a link. For the regex tool, the test string is included only if you explicitly opt in.
