Install & first launchインストールと初回起動

Get Sharebar from the Mac App Store. It lives in the menu bar (no Dock icon). There is no permission prompt at launch — the pasteboard permission only comes up when you actually use a tool, and Settings explains all three permission states with a direct link to System Settings.

Sharebar は Mac App Store から入手できます。メニューバーに常駐し、Dock にアイコンは出ません。起動時に許可ダイアログは出ません — ペーストボード許可が関わるのは実際にツールを使うときだけで、3つの許可状態は設定画面で説明され、システム設定へのリンクも用意されています。

02

Smart Detectスマート検出

When you open the popover, Sharebar checks the clipboard once and suggests the matching tool — JSON, Base64, URL-encoded, Unix time, UUID, color, cron or a hash digest. When more than one type fits, a “Detected:” chip row shows the candidates — tap one to switch. The top match is highlighted; press Enter to run it. It never polls in the background.

ポップオーバーを開くと、Sharebar はクリップボードを一度だけ確認し、合うツールを提案します — JSON・Base64・URLエンコード・Unix time・UUID・カラー・cron・ハッシュダイジェスト。複数の型が当てはまるときは「検出:」チップに候補が並び、タップで切り替え。最有力候補がハイライトされ、Enter で実行できます。バックグラウンドで監視することはありません。

One-click convertワンクリック変換

The everyday loop is copy → click → Enter → paste. Every successful convert auto-copies its result with a “Copied” toast, and an Undo restores whatever was on your clipboard before.

日常のループは、コピー → クリック → Enter → ペースト。変換が成功するたびに結果は自動コピーされ、「コピーしました」のトーストが出ます。「元に戻す」で直前のクリップボード内容を復元できます。

Make a Share Link共有リンクを作る

On regex, cron, color or unix-time, hit Share. A Share Preview shows the exact, full content that goes into the URL — nothing leaves your machine unseen. For regex, the test string is excluded by default. Confirm to copy the link.

regex・cron・color・unix-time で「共有」を押すと、URL に入る内容の全文が共有プレビューに表示されます — 見えないままマシンの外に出るものはありません。regex のテスト文字列は既定で除外。確認したらリンクをコピーします。

Open a shared link共有リンクを開く

Anyone can open a Share Link in a browser — no app, any OS. The share page reproduces the result with the same engine and lets them tweak values live. Their edits never write back to the link. “Open in Sharebar” restores the state in the app.

共有リンクはブラウザさえあれば誰でも開けます — アプリ不要、OS も問いません。共有ページは同じエンジンで結果を再現し、値をその場で編集できます。編集がリンクに書き戻されることはありません。「Sharebar で開く」を押すと、アプリに状態を復元します。

Pasteboard permissionペーストボード許可

macOS 26 has three pasteboard states. Sharebar follows them honestly — and Deny never blocks you, because ⌘V always works.

macOS 26 のペーストボード許可には3つの状態があります。Sharebar はそれに正直に従います — 「拒否」でも困りません。⌘V はいつでも使えます。

Allow許可

Smart Detect reads the clipboard once when you open the popover and shows what it read.

ポップオーバーを開いたときに一度だけクリップボードを読み、何を読んだかを表示します。

Ask毎回確認

It suggests a type without reading the contents until you actually run a tool.

内容は読まずに型だけを提案し、実際にツールを実行するまで読み取りません。

Deny拒否

It skips reading entirely and drops to manual input — paste or type yourself.

読み取りを完全にスキップして手動入力に — 自分でペーストするか入力します。

We never say “one-time prompt” — Sharebar follows the real macOS 26 behavior honestly.「確認は一度だけ」とは言いません — Sharebar は macOS 26 の実際の挙動に正直に従います。

Settings & shortcuts設定とショートカット

One screen of settings: record an optional global hotkey with the “Record Shortcut” button (unset by default), launch at login (off), Smart Detect on/off, default JSON indent, pinned tools, a link to the pasteboard permission in System Settings — plus a Support section with the optional Tip Jar. Arrow keys and incremental search keep you off the mouse.

設定は1画面: 「ショートカットを記録」ボタンで任意のグローバルホットキーを登録（既定は未割当）、ログイン時に起動（既定オフ）、スマート検出のオン/オフ、JSON の既定インデント、ピン留めツールの管理、システム設定のペーストボード許可へのリンク — さらに任意のチップ（Tip Jar）があるサポートセクション。矢印キーとインクリメンタル検索で、マウスいらず。

Keyboard shortcutsキーボードショートカット

Sharebar is built for the keyboard. A recorded global hotkey opens the popover from anywhere; inside it, ⌘⇧J / ⌘⇧B / ⌘⇧U jump straight to JSON / Base64 / URL Encode without auto-running, and in the JSON tool ⌘1 / ⌘2 / ⌘3 run Pretty / Minify / Validate. Arrow keys and incremental search move through the list; Enter runs the selection.

Sharebar はキーボード前提で作られています。登録したグローバルホットキーでどこからでもポップオーバーを開き、⌘⇧J / ⌘⇧B / ⌘⇧U で JSON / Base64 / URL Encode へ直行（自動実行はしません）。JSON ツール内では ⌘1 / ⌘2 / ⌘3 が整形 / 圧縮 / 検証。矢印キーとインクリメンタル検索でリストを移動し、Enter で実行します。

Privacyプライバシー

Nothing is stored or sent. No clipboard contents, no input, no link history, no analytics. Only settings, pins and window position live in app storage. App Privacy is “Data Not Collected.”

何も保存せず、何も送信しません。クリップボードの内容も、入力も、リンク履歴も、アナリティクスもなし。アプリが保存するのは設定・ピン留め・ウィンドウ位置だけ。App Store のプライバシー表示は「データ収集なし」です。

FAQ

QDoes the receiver need the app?受け取る側にアプリは必要？
No. The share page works in any browser on any OS. The app only adds “Open in Sharebar.”不要です。共有ページはどの OS のどのブラウザでも動きます。アプリがあると「Sharebar で開く」が使えるようになるだけです。
QCan a JSON or diff be shared?JSON や diff は共有できる？
No — by design. Only regex, cron, color and unix-time produce links, so confidential data can't end up in a URL.できません — 意図的な設計です。リンクを作れるのは regex・cron・color・unix-time だけなので、機密データが URL に入ることがありません。
QWhere is the link stored?リンクはどこに保存される？
Nowhere. The whole state is in the URL fragment. No server, no shortener. If the link text survives, the state survives.どこにも保存されません。状態はすべて URL フラグメントの中です。サーバーも短縮 URL もなし。リンクの文字列が残るかぎり、状態も残ります。
QWhat regex flavor is it?正規表現の方式は？
JavaScript flavor, flags gimsuy. The app and the page evaluate identically.JavaScript 方式、フラグは gimsuy。アプリとページの評価結果は同一です。
QWill old links keep working?古いリンクは動き続ける？
Yes. v1 links open forever and evaluate the same forever — even offline via manual open in the app.はい。v1 リンクはこれからも開け、常に同じ結果に評価されます — アプリの「共有リンクを開く…」からならオフラインでも。
QWhat is the Tip Jar?チップ（Tip Jar）って何？
An optional in-app tip to support development, processed by Apple. Nothing is unlocked — every feature is free for everyone.開発を応援できる任意のアプリ内チップです。決済は Apple が処理します。機能は何も解除されません — すべての機能が誰でも無料です。
