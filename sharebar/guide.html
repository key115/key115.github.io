Smart Detect

When you open the popover, Sharebar checks the clipboard once and suggests the matching tool — JSON, Base64, URL-encoded, Unix time, UUID, color or cron. When more than one type fits, a “Detected:” chip row shows the candidates — tap one to switch. The top match is highlighted; press Enter to run it. It never polls in the background.

Make a Share Link

On regex, cron, color or unix-time, hit Share. A Share Preview shows the exact, full content that goes into the URL — nothing leaves your machine unseen. For regex, the test string is excluded by default. Confirm to copy the link.

07

Pasteboard permission

macOS 26 has three pasteboard states. Sharebar follows them honestly — and Deny never blocks you, because ⌘V always works.

Allow

Smart Detect reads the clipboard once when you open the popover and shows what it read.

Ask

It suggests a type without reading the contents until you actually run a tool.

Deny

It skips reading entirely and drops to manual input — paste or type yourself.

We never say “one-time prompt” — Sharebar follows the real macOS 26 behavior honestly.

Keyboard shortcuts

Sharebar is built for the keyboard. A recorded global hotkey opens the popover from anywhere; inside it, ⌘⇧J / ⌘⇧B / ⌘⇧U jump straight to JSON / Base64 / UUID without auto-running, and in the JSON tool ⌘1 / ⌘2 / ⌘3 run Pretty / Minify / Validate. Arrow keys and incremental search move through the list; Enter runs the selection.

Privacy

Nothing is stored or sent. No clipboard contents, no input, no link history, no analytics. Only settings, pins and window position live in app storage. App Privacy is “Data Not Collected.”

FAQ

QDoes the receiver need the app?
No. The share page works in any browser on any OS. The app only adds “Open in Sharebar.”
QCan a JSON or diff be shared?
No — by design. Only regex, cron, color and unix-time produce links, so confidential data can't end up in a URL.
QWhere is the link stored?
Nowhere. The whole state is in the URL fragment. No server, no shortener. If the link text survives, the state survives.
QWhat regex flavor is it?
JavaScript flavor, flags gimsuy. The app and the page evaluate identically.
QWill old links keep working?
Yes. v1 links open forever and evaluate the same forever — even offline via manual open in the app.
