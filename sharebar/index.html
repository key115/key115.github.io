Same engine, both sides送り手も受け手も、同じエンジン

The app and the share page run one identical JavaScript core. The regex you test in the menu bar matches byte-for-byte in the receiver's browser — there is no second implementation to drift.

アプリと共有ページは、同一の JavaScript コアを実行します。メニューバーでテストした正規表現は、受け取り側のブラウザでもバイト単位で同じ結果に — 実装が2つに分かれてズレることがありません。

When it's worth sharing共有したくなったら

Hit Share on a regex, cron, color or unix-time. A preview shows exactly what goes in the URL — then you get a self-contained link to paste anywhere.

regex・cron・color・unix-time で「共有」を押すと、URL に入る内容がそのまま共有プレビューに表示されます。確認したら、どこにでも貼れる自己完結リンクをコピー。

Your data never leaves your Mac — the link is the dataデータは Mac の外に出ません — リンクそのものがデータ
The app itself makes no network connections, holds no network entitlement, and collects no data — a third party can confirm the entitlements with codesign. Optional tips are processed by Apple’s App Store outside the app. Data-carrying tools can't make a link at all, so confidential data has no path into a URL.アプリ自身は外部通信を行わず、ネットワーク権限も持たず、データ収集もありません — entitlements は codesign で第三者が確認できます。任意のチップは Apple の App Store がアプリ外で処理します。データ運搬系のツールはそもそもリンクを作れないため、機密データが URL に入る経路がありません。
