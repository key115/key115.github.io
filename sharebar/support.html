Supportサポート

Last updated: 2026-08-12最終更新: 2026-08-12

New to the app, or want a walkthrough of every tool? See the full guide & reference. This page focuses on how Share Links and the Share Page work, and how to get help.

アプリが初めての方、全ツールの説明が見たい方はガイド＆全リファレンスへ。このページでは、共有リンクと共有ページの仕組み、困ったときの対処を説明します。

What is a Share Link?共有リンクとは？

A Share Link reproduces the exact state of a Sharebar tool. The whole state is encoded in the URL, so opening the link in any browser shows the same result the sender saw — and you can edit the values to re-run it. Four tools can be shared: regex, cron, color, and unix-time.

共有リンクは、Sharebar ツールの状態をそのまま再現するリンクです。状態はすべて URL にエンコードされているため、どのブラウザで開いても送り手が見たのと同じ結果が表示され、値を編集して再実行することもできます。共有できるのは regex・cron・color・unix-time の4ツールです。

Opening a linkリンクを開く

Just open the link in your browser. The Share Page decodes it locally and shows the reproduced result. Change any field to re-run it instantly; your edits stay on your screen and are never written back into the link.

リンクをブラウザで開くだけです。共有ページがローカルでデコードし、再現結果を表示します。フィールドを変更すると即座に再実行されます。編集はあなたの画面の中だけで、リンクに書き戻されることはありません。

“Open in Sharebar”「Sharebar で開く」

If you have the Mac app installed, the Open in Sharebar button hands the shared state to the app. If the app isn’t installed, the page falls back gracefully and points you to Get the app.

Mac アプリをインストール済みなら、「Sharebar で開く」ボタンで共有状態をアプリに引き渡せます。未インストールの場合は、ページがそのまま「アプリを入手」を案内します。

Why the same result on both sides?なぜ両側で同じ結果になる？

The app and this page run one identical JavaScript core. That means the regex engine, the cron schedule math, the color conversions, and the Unix-time breakdown are exactly the same in both places — there is no second implementation to drift.

アプリとこのページが、同一の JavaScript コアを実行しているからです。正規表現エンジンも、cron のスケジュール計算も、カラー変換も、Unix time の分解も、両側で完全に同じ — ズレる余地のある第2実装が存在しません。

Is anything uploaded?何かアップロードされる？

No. There is no server. The shared state lives in the URL fragment, which browsers never transmit. See Privacy for details.

いいえ。サーバーは存在しません。共有状態は URL フラグメントの中にあり、ブラウザはフラグメントをサーバーに送信しません。詳細はプライバシーをご覧ください。

A link won’t openリンクが開かない

If a link is damaged, truncated, or made by a newer version of Sharebar, the page tells you so rather than failing silently. Ask the sender to re-share, or update the app.

リンクが破損・途中で切れている、またはより新しいバージョンの Sharebar で作られている場合は、黙って失敗せず、その旨を表示します。送り手に再共有を頼むか、アプリを更新してください。
