01 / A IDEIA

Menos procurar.Mais criar.

Uma frase de uma página. Um link para depois. Uma imagem que inspirou algo. O ClipRecall mantém suas cópias recentes por perto para sua próxima ideia não precisar esperar.

  1. 01⌘+C

    Copie

    Texto, links, HTML e imagens. Copie como sempre.

  2. 02⌥+V

    Recupere

    Pressione Option + V. Escolha algo do histórico recente.

  3. 03⌘+V

    Continue

    Pressione Return para recuperar e Command + V para colar.

02 / SEU MAC. SUA MEMÓRIA.

O que importa,perto de você.

O conteúdo da área de transferência fica no seu Mac. O histórico comum fica na memória; os itens fixados são criptografados localmente. Sem conta, sincronização na nuvem ou análise de uso.
