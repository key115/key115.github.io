FAQ

Do I need to grant any permission?
ClipRecall requests no permission at launch — selecting an item puts it back on your clipboard for a manual ⌘V paste. The optional Direct Paste feature can paste for you once you enable it in System Settings and restart ClipRecall. On macOS 26, the system itself may ask you to confirm clipboard access; see the next question.
macOS 26 shows a confirmation dialog, or new copies stop appearing?
macOS 26 manages clipboard reading per app in System Settings > Privacy & Security > Paste from Other Apps. Set ClipRecall to Allow there so it can capture new copies. Even if it stays on Deny, restoring pinned items and pasting with ⌘V keep working.
How is ClipRecall different from the clipboard history built into macOS 26 (Spotlight)?
Four ways. ClipRecall captures images and rich content — the built-in Spotlight history is plain text only. Pinned items are kept permanently, encrypted locally with AES-GCM. It opens a dedicated Option + V panel you can restyle like your terminal. And it works on macOS 14.0 or later, not just macOS 26.
Does it sync across devices?
No. Everything stays on this Mac — there is no cloud sync or account.
