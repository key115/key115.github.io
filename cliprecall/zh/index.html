01 / 理念

少一点寻找。多一点创造。

网页上的一句话，稍后要看的链接，带来灵感的一张图片。ClipRecall 让最近的复制内容触手可及，让思路继续向前。

  1. 01⌘+C

    复制

    文字、链接、HTML 和图片。像平时一样复制。

  2. 02⌥+V

    唤回

    按 Option + V，选取最近的历史记录。

  3. 03⌘+V

    继续

    按 Return 恢复到剪贴板，再按 Command + V 粘贴。

02 / 你的 Mac，你的记忆

重要的内容，留在身边。

剪贴板内容只留在你的 Mac 上。普通历史记录保存在内存中，固定的项目在本地加密保存。无需账户，没有云同步，也没有分析追踪。
