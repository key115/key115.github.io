01

开始使用

从 Mac App Store 安装并打开 ClipRecall。它会驻留在菜单栏中。历史记录默认开启，从应用运行期间的新复制内容开始记录。

  1. 1. 复制

    ⌘+C

    复制想要再次使用的文字、链接、HTML 或图片。每个项目最多 4 MB。

  2. 2. 唤回

    ⌥+V

    按 Option + V 打开历史记录。用上下方向键选择项目，也可以点击项目直接恢复。

  3. 3. 继续

    Return → ⌘ V

    按 Return 将所选项目恢复到剪贴板，然后在目标应用中按 Command + V 粘贴。这是默认行为。

想少按一步？

在设置中开启“直接粘贴”，即可在选择后自动粘贴。此功能默认关闭。请按提示授予权限，必要时重启 ClipRecall。权限生效前，选择项目仍会恢复剪贴板内容，可用 Command + V 粘贴。

快捷键

以上方向键操作适用于历史标签。在颜文字和符号网格中，方向键用于选择字符。全局快捷键可在设置中更改。

03

留住重要内容

恢复之前，先看清内容。

将指针停在历史项目上，或按右方向键，即可打开内容预览。长内容可用 Page Up、Page Down、Home 和 End 浏览。悬停预览可在设置中关闭。

值得保留的，固定下来。

点击项目的固定按钮，可在重启应用后保留。固定项目在 Mac 本地加密保存，不占用普通历史记录的 25 项限额。“全部清除”只会删除未固定的历史。

04

个性化设置

让它融入你的桌面。

05

常见问题

为什么退出后历史记录消失了？+

普通历史只保存在内存中，不会跨会话保留。需要保留的内容请固定。如果出现存储警告，请先确认新固定的项目已保存。

如何暂停或删除历史记录？+

处理敏感内容前，可从菜单栏暂停历史记录。可以逐项删除，或用“全部清除”删除未固定的历史。“删除所有数据”是另一项需确认的操作，也会删除固定项目、保存的数据和当前系统剪贴板。

剪贴板内容会离开我的 Mac 吗？+

不会。ClipRecall 不会发送或同步剪贴板内容，也不包含分析追踪。可选的打赏购买由 Apple 通过 StoreKit 单独处理。
