01 / LA IDEA

Menos buscar.Más crear.

Una frase de una página. Un enlace para después. Una imagen que inspiró algo. ClipRecall mantiene cerca tus copias recientes para que tu próxima idea no tenga que esperar.

  1. 01⌘+C

    Copia

    Texto, enlaces, HTML e imágenes. Copia como siempre.

  2. 02⌥+V

    Recupera

    Pulsa Option + V. Elige algo de tu historial reciente.

  3. 03⌘+V

    Continúa

    Pulsa Return para recuperarlo y Command + V para pegarlo.

02 / TU MAC. TU MEMORIA.

Lo importante,cerca de ti.

El contenido del portapapeles permanece en tu Mac. El historial normal vive en memoria; los elementos fijados se cifran localmente. Sin cuenta, sincronización en la nube ni analítica.
