01

Primeros pasos

Instala ClipRecall desde Mac App Store y ábrelo. Se queda en la barra de menús. La captura está activada por defecto y registra las nuevas copias mientras la app está abierta.

  1. 1. Copia

    ⌘+C

    Copia texto, enlaces, HTML o imágenes que quieras reutilizar. Se admiten hasta 4 MB por elemento.

  2. 2. Recupera

    ⌥+V

    Abre el historial con Option + V. Selecciona con las flechas arriba y abajo, o haz clic en un elemento para recuperarlo.

  3. 3. Continúa

    Return → ⌘ V

    Pulsa Return para devolver el elemento al portapapeles. Después, pulsa Command + V en la app de destino. Este es el comportamiento predeterminado.

¿Prefieres un paso menos?

Activa Pegado directo en los ajustes. Está desactivado por defecto. Sigue las indicaciones de permisos y reinicia ClipRecall si se solicita. Mientras el permiso no esté listo, el elemento vuelve al portapapeles y puedes pegarlo con Command + V.

03

Conserva lo importante

Lee antes de recuperar.

Deja el puntero sobre una fila o pulsa la flecha derecha para abrir la vista previa. Usa Page Up, Page Down, Home y End para recorrer textos largos. Puedes desactivar la vista previa al pasar el puntero en los ajustes.

Fija lo que quieras guardar.

Fija un elemento para conservarlo al reiniciar la app. Se cifra en tu Mac y no cuenta para el límite de 25 elementos del historial normal. Borrar todo solo elimina el historial no fijado.

04

A tu manera

En armonía con tu escritorio.

Elige densidad Estándar o Compacta. Ajusta el fondo, el color del texto, la opacidad y el desenfoque, o usa un preajuste. Cambia el atajo global y el idioma de la app en los ajustes.

05

Preguntas frecuentes

¿Por qué desaparece el historial al salir?+

El historial normal solo se guarda en memoria y no se conserva entre sesiones. Fija lo que quieras mantener. Si aparece una advertencia de almacenamiento, comprueba que el elemento fijado se haya guardado.

¿Cómo pauso o elimino el historial?+

Pausa la captura desde la barra de menús antes de trabajar con información sensible. Elimina elementos o usa Borrar todo para los no fijados. Eliminar todos los datos es una acción aparte con confirmación: también borra los elementos fijados, los datos guardados y el portapapeles actual del sistema.

¿Se envía fuera de mi Mac lo que copio?+

No. ClipRecall no envía ni sincroniza el contenido y no incluye analítica. Las propinas opcionales se procesan por separado mediante StoreKit de Apple.
