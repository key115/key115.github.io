TypeBack とは

TypeBack は、Mac のキーボード入力に合わせてレトロな作業音をローカルで再生するメニューバーアプリです。完全ローカル動作・データ収集なし・買い切り。

はじめ方

ステップ 1: アプリを起動する

アプリを起動すると、画面右上のメニューバーに TypeBack のアイコンが表示されます。

ステップ 2: 入力監視を許可する

初回起動時に、入力監視の案内が表示されます。以下の手順で権限を付与してください。

  1. システム設定 を開く
  2. プライバシーとセキュリティ を選択
  3. 入力監視 を選択
  4. TypeBack のスイッチを オン にする
TypeBack が一覧に表示されない場合
入力監視画面の + ボタンから TypeBack.app を手動で追加し、スイッチをオンにしてください。その後、TypeBack を一度終了して再起動してください。
なぜこの権限が必要なのか？
他のアプリでキーが押された「タイミング」を検知して、対応する音をローカルで鳴らすためです。入力した文字の内容は一切読み取りません。

ステップ 3: 音を ON にする

メニューバーのアイコンをクリック → 設定ポップオーバーが開きます。サウンド のトグルをオンにして、キーボードを打ってみてください。

使い方

サウンドパックを切り替える

設定ポップオーバーの サウンドパック から、好みのパックを選択できます。

パック名雰囲気

音量を調整する

設定ポップオーバーの 音量 スライダーで調整できます。

ログイン時に自動起動する

設定ポップオーバーの ログイン時に起動 をオンにすると、Mac 起動時に自動的に起動します。

アプリを終了する

設定ポップオーバー下部の 終了 ボタンを押すと、アプリが終了します。

よくある質問

音が鳴りません

以下を順番に確認してください。

  1. 設定ポップオーバーの サウンド トグルが オン になっているか確認
  2. 入力監視 が許可されているか確認（システム設定 → プライバシーとセキュリティ → 入力監視 → TypeBack がオンか）
  3. TypeBack が一覧に表示されない場合は、+ から TypeBack.app を手動で追加し、オンにしてから再起動
  4. Mac のスピーカーまたはヘッドホンの音量がミュートになっていないか確認
  5. アプリを一度終了して再起動
メニューバーにアイコンが表示されない

アプリが起動しているか確認してください。アプリケーションフォルダから TypeBack をダブルクリックして起動します。

入力監視を許可したが音が鳴らない

入力監視の一覧で TypeBack がオンになっているか確認してください。一覧に表示されない場合は、+ から TypeBack.app を手動で追加し、オンにしてからアプリを再起動してください。

キーの内容は記録されていますか？

いいえ。 TypeBack はキーが押された「タイミング」と「種別」（通常キー / Enter / Space / Backspace 等）のみを利用します。入力された文字や内容は一切読み取らず、保存・送信もしません。

インターネットに接続されていますか？

いいえ。 TypeBack は完全にローカルで動作します。外部サーバーとの通信は一切行いません。

アプリをアンインストールするには？

アプリケーションフォルダの TypeBack をゴミ箱に移動し、ゴミ箱を空にしてください。保存されたデータ（設定）も一緒に削除されます。

macOS 14 より古い環境で使えますか？

macOS 14.0（Sonoma）以降が必要です。古い macOS には対応していません。

App: TypeBack ／ Requires: macOS 14.0 or later ／ Last updated: 2026-05-13

What is TypeBack?

TypeBack is a macOS menu bar utility that plays retro typing sounds locally on your Mac in response to your keystrokes. Fully offline. No data collection. One-time purchase.

Getting Started

Step 1: Launch the App

After launching TypeBack, its icon will appear in the menu bar at the top right of your screen.

Step 2: Grant Input Monitoring Permission

On first launch, TypeBack will guide you to grant Input Monitoring permission.

  1. Open System Settings
  2. Select Privacy & Security
  3. Select Input Monitoring
  4. Enable the toggle next to TypeBack
If TypeBack does not appear in the list
Use the + button in Input Monitoring to add TypeBack.app manually, turn it on, then quit and relaunch TypeBack.
Why is this permission needed?
TypeBack uses it to detect when a key is pressed in other apps so it can play the corresponding sound locally. It does not read what you type.

Step 3: Turn On Sound

Click the TypeBack icon in the menu bar → the settings popover opens. Toggle Sound on and start typing to hear the retro sounds.

How to Use

Switch Sound Packs

In the settings popover, tap Sound Pack to choose a different theme.

Use the Volume slider in the settings popover.

Enable Launch at Login in the settings popover to start TypeBack automatically when your Mac starts up.

Quit the App

Press the Quit button at the bottom of the settings popover.

FAQ

No sound is playing
  1. Confirm the Sound toggle in the settings popover is on
  2. Confirm Input Monitoring permission is granted (System Settings → Privacy & Security → Input Monitoring → TypeBack is on)
  3. If TypeBack does not appear in the list, use + to add TypeBack.app manually, turn it on, then relaunch the app
  4. Confirm your Mac's speaker or headphone volume is not muted
  5. Quit and relaunch the app
The menu bar icon is not visible

Make sure TypeBack is running. Open the Applications folder and double-click TypeBack.

I granted Input Monitoring permission but still no sound

Confirm TypeBack is turned on in the Input Monitoring list. If it does not appear, use + to add TypeBack.app manually, turn it on, then quit and relaunch TypeBack.

Does TypeBack record what I type?

No. TypeBack uses only the type of key pressed (normal / Enter / Space / Backspace, etc.) — never the content. Nothing you type is read, stored, or transmitted.

Does TypeBack make network requests?

No. TypeBack works entirely offline with no network requests of any kind.

How do I uninstall TypeBack?

Move TypeBack from the Applications folder to the Trash, then empty the Trash. All saved settings will be removed along with the app.

What macOS versions are supported?

macOS 14.0 (Sonoma) or later is required.
